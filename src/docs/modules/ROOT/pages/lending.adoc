== Borrowers

A borrower is anyone you lend items to — a friend, a family member, a colleague.
Borrowers are managed from *Settings > Borrowers*, where you can search your existing list, add a new borrower, and see which of your items each person currently has on loan.

A borrower record only needs a name; email and phone are optional extras if you want to note how to reach them.

== Lending an item

. Open the item's detail screen — see xref:item-details.adoc[Item Details].
. In the *Lending* section, tap *Lend*.
. Pick an existing borrower from the list, or choose *Add new borrower* to create one there and then.
. Optionally, set a due date for when it should come back.
. Confirm to record the loan.

Once an item is on loan, its detail screen shows who has it, the due date if you set one, and an overdue indicator once that date has passed.
You can change the due date at any time from the same screen.

WARNING: An item can only be on loan to one borrower at a time.
Return it before lending it to someone else.

== Getting it back

Open the item's detail screen and tap *Return* on the active loan.
The loan closes immediately and the item is available to lend again.

Every closed loan stays visible in a loan history list on the item's detail screen, so you can see who has borrowed it in the past and when.

== Overdue reminders

NOTE: MyMediaScanner can notify you when a loan becomes overdue.
This requires notification permission, which the app asks for the first time you launch it.
