= Scanning Barcodes
include::_attributes.adoc[]
:description: How to scan a barcode on every platform MyMediaScanner supports, choose a media-type filter, and what happens if a barcode isn't recognised.

Scanning a barcode is the fastest way to add an item to your collection.
Point a camera at it, run it past a USB scanner, or type it in, and MyMediaScanner looks up the metadata and lets you confirm the result before it's saved.

image::screenshots/ios/scanner.png[The scan screen with its live camera viewfinder,role=screenshot,width=360]

TIP: Got a barcode that photographs badly, or an item with no barcode at all?
See xref:manual-add.adoc[Manual Add] for typing an identifier by hand or filling in the details yourself.

== Scanning methods by platform

[cols="1,2,2",options="header"]
|===
| Platform | Primary method | Also available

| Android and iOS
| Device camera, live viewfinder
| A connected Bluetooth or USB barcode scanner

| macOS
| Device camera, live viewfinder
| A USB keyboard-wedge barcode scanner, or typing the barcode by hand

| Windows and Linux
| A USB keyboard-wedge barcode scanner, or typing the barcode by hand
| A webcam (checked periodically rather than as a smooth live feed)
|===

On macOS, Windows, and Linux, a toggle button in the scan screen's toolbar switches between the keyboard/USB view and the camera or webcam view.

== Phone and tablet camera

On Android and iOS, the scan screen shows a live camera preview with a targeting reticle.
Hold the barcode inside the frame and, as soon as it's recognised, you'll see a confirmation animation together with a short vibration and tone.
The camera then pauses while the metadata lookup runs, so you can't accidentally scan the same item twice in a row.

== macOS camera

macOS also gets a live camera viewfinder, just like a phone or tablet.
Because macOS is treated as a desktop platform, it normally shows the keyboard/USB view first — tap the webcam icon in the toolbar to switch to the live camera view, and tap it again to switch back.

== Windows and Linux webcam

Tap the webcam icon in the toolbar to scan with a connected webcam instead of a USB scanner or the keyboard.
Unlike the phone/tablet and macOS camera views, Windows and Linux check a fresh still image every so often rather than a continuous live feed, so hold the barcode steady for a moment while it's captured.

== USB keyboard-wedge scanners

On macOS, Windows, and Linux, the scan screen keeps a text field focused and ready at all times whenever you're not using the camera or webcam view.
A keyboard-wedge USB barcode scanner types the barcode's digits followed by an Enter keystroke, exactly as if you'd typed it yourself — so scanning an item with the field in focus starts the metadata lookup automatically, with no clicking required.

TIP: On desktop you can also jump straight to the Scan screen with `Ctrl+N`.

== Bluetooth and USB scanners on mobile

On Android and iOS, tap the Bluetooth/scanner icon beside the viewfinder to switch from the device camera to *Bluetooth / USB Scanner Mode*.
In this mode the viewfinder is replaced by a text field that accepts input from a connected external scanner in the same way as a keyboard-wedge scanner on desktop.
Tap the icon again to switch back to the device camera.

== Choosing a media-type filter

Below the scan controls, a row of filter chips lets you narrow the lookup to a particular media type: *CD* (music), *DVD/Blu-ray* (film), *TV*, *Book*, or *Game*.
Toggling a type off tells the app not to route lookups for that type — useful if you're scanning a mixed stack and know it's all, say, books.
Narrowing to the right type matters most for barcodes that could plausibly belong to more than one kind of item, since it decides which online source is tried first (music barcodes go to MusicBrainz or Discogs, film/TV barcodes go to TMDB, and so on).

NOTE: Film and TV lookups need a TMDB API key to work at all.
See xref:api-keys.adoc[API Keys] if lookups for those types aren't returning anything.

== When a barcode isn't recognised

If none of the online sources can find metadata for a barcode, you'll see a *Barcode Not Found* message with three choices:

* *Scan again* (or *Try again*) — dismiss the message and go back to scanning.
* *Enter manually* — go straight to the metadata form and fill in the details yourself.
* *Scan cover* (mobile) or *Pick cover image* / *Capture cover* (desktop) — read text off the item's cover to help find it by title instead of by barcode.

See xref:manual-add.adoc[Manual Add] for what happens next on each of those paths, including the platform limits on reading text from a cover photo.
