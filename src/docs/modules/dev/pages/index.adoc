== Conventions

* Repository interfaces live in `domain/repositories/` and are prefixed with `I`.
* Riverpod providers are hand-written; `riverpod_generator` is not used, because it conflicts with `drift_dev`.
* Platform checks go through `core/utils/platform_utils.dart` rather than `dart:io Platform`.
* Deletes are soft: set `deleted = 1` so the row still syncs.

Each feature page states the constraints that apply to it, and those constraints are usually the reason the code looks the way it does rather than incidental detail.
